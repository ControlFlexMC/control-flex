# Control Flex 0.9.0-beta.1

**新特性：**
- 光标与虚拟滚轮四档速度 —— 按摇杆推幅分慢 / 中 / 快 / 满，切分点可拖（老用户需手动开启，新用户默认开启）
- 界面动作菜单 —— 每界面最多 5 个菜单 × 12 个动作，纯浮层，不占新键位
- 径向菜单 —— 12 格、实时物品数量、缺失 / 未知状态、冷却填充
- 载具输入模式 —— 模拟 / 八向 / WASD，在 compat 配置里声明
- 桥接 API 0.9.2.2 —— 原生动作注册、界面处理器、绑定查询

**修复：**
- Windows：支持 JNI 和 JNA 双通道调用 SDL3 库，避免在 gamepadjni.dll 积累到足够信誉前，被 Windows 11 SAC 拦截后，无法识别手柄的问题
- Linux：可识别热插拔的手柄，无需重启MC
- macOS：菜单里从手柄切到键鼠后，光标不再变成隐形
- 在 compat 配置里做第一次编辑，不再丢掉继承来的键
