# Control Flex 0.8.8-beta.2

**Features:**
- Analog 360° stick movement
- Double-trigger modes (Double Press / Tap / Hold / Toggle)
- Dual Sneak & Sprint actions — each now has separate hold & toggle bindings
- Per-page Screen & Overlay rebinding
- New Smooth Turn camera mode
- Background input support — works with the Split-Screen mod
- Back Button Mapping with configurable keyboard ranges

**Fixes:**  
- Virtual KBM capture highlight isolated to the clicked row
- fix #4: rebinding from Controller Picks up GUI Press button

**Tuning:**  
- Community Repo auto-apply
- Mod adaptation shows declared compat dependencies
