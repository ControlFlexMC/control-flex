# Control Flex 0.8.9-beta.1

**新特性：**
- 屏幕键盘支持所有界面 —— QWERTY / A–Z，3 行或 4 行
- ChatScreen 新增 Quick Text 与发送历史
- Android 支持 —— ZalithLauncher2 > 2.7、FoldCraftLauncher >= 1.3.4.0（MojoLauncher / Amethyst 需等其新版本）
- 回移植 —— MC 1.19.2 / 1.18.2 / 1.16.5 / 1.12.2 / 1.10.2

**修复：**  
- fix #9：PS4/PS5 手柄图标与按钮名改为跟随最后连接的手柄
- fix #10：点按类跳跃在水里不再只上浮一次

**调整：**  
- 屏幕键盘默认开启，默认四行 QWERTY 布局
- Profile 升级到 v5；聊天与退格默认值只补进空槽位
