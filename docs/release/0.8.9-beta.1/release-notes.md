# Control Flex 0.8.9-beta.1

**Features:**
- On-Screen Keyboard on every screen — QWERTY / A–Z, 3 or 4 rows
- Quick Text and sent history in ChatScreen
- Android support — ZalithLauncher2 > 2.7, FoldCraftLauncher >= 1.3.4.0 (MojoLauncher / Amethyst need their next release)
- Backports — MC 1.19.2 / 1.18.2 / 1.16.5 / 1.12.2 / 1.10.2

**Fixes:**  
- fix #9: PS4/PS5 glyphs and button names now follow the last connected pad
- fix #10: one-shot jump presses stay held through the swim-up in water

**Tuning:**  
- On-Screen Keyboard is on by default, on a four-row QWERTY board
- Profiles migrate to v5; chat and backspace defaults are seeded only into empty slots
